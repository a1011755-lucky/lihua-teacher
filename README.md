# 理化小老師 · 測試版

## 怎麼打開
直接用滑鼠**雙擊 `index.html`**，用 Chrome 或 Edge 打開即可，不需要安裝任何東西、不用連 AI。

## 測試版做得到的
- **題型**：等加速度直線運動（煞車、加速、求時間、求滑行距離），題目要有數字和單位（m/s、km/h、秒、m/s²、公尺）。
- **一步一步講解**：定義正方向 → 列已知數 → 代公式 → 解釋答案的意思。
- **找學生錯在哪**：填入學生的答案，會指出常見錯誤（正負號相反、忘了除以時間、把變速當等速、漏了 ½……）。
- **動畫**：車子移動＋速度／加速度箭頭＋速度–時間圖（面積＝位移），可開語音朗讀。
- **題庫**：問過的題目會存起來（換個問法也認得出來），統計被問次數、學生常見錯誤答案；老師後台可以審核、刪除、匯出備份。

## 雲端題庫（Firebase）
- `firebase-config.js` 填好 Firebase 設定後，題庫自動改存雲端（右上角會顯示「☁ 雲端題庫」）；沒填時顯示「💻 本機題庫」，存在這台電腦。
- `firestore.rules` 是資料庫安全規則：學生只能新增題目、把被問次數加 1；**只有老師（a1011755@gmail.com）登入後**才能審核、刪除。修改後要貼到 Firebase 主控台 → Firestore Database → 規則 → 發布。
- 老師登入在「題庫（老師後台）」分頁。直接雙擊檔案打開時可能無法登入，放上網站後就可以。

## 單元動畫教室（國三上第一、二章）
- `lessons.js`：單元題庫，每題有「一步一步講解＋動畫設定＋常見錯誤答案」。目前 27 題（直線運動 12 題、力與運動 15 題）。
- `scenes.js`：動畫引擎。每題的動畫只是一組參數（例如 `{type:"forces", m:4, forces:[…]}`），可用類型：直線運動、單擺、受力分析、慣性、作用反作用、圓周運動、萬有引力。
- 學生問的題目和題庫很像時（數字、單位都要一樣），直接用題庫的講解，0 token；有點像但不確定時，會問學生「是不是這一題？」。
- 解題模板：等加速度直線運動、F = m × a（含摩擦力、kgw 換算）任何數字都能算，並附動畫。
- 新增題目：照 `lessons.js` 的格式加一題即可（可以請 Claude 幫忙寫）。

## 拍照解題
- 「📷 拍照／選照片」：照片在學生手機上直接辨識成文字（Tesseract.js，免費），學生檢查、改錯字後再按「請老師解答」。
- 解題模板會的題型 → 直接算，0 token。模板不會、或照片字看不清楚 → 交給 AI 老師（照片＋文字一起送）。

## AI 老師（Claude）
- 網頁不直接放 Claude 金鑰，而是經過 `ai-worker/` 這個 Cloudflare Worker 中繼站（金鑰存在 Cloudflare 的祕密變數 `ANTHROPIC_API_KEY`）。
- 中繼站網址填在 `firebase-config.js` 的 `window.AI_URL`；空白時不會呼叫 AI。
- AI 的解答會存進題庫（狀態「待審核」），之後同一題直接從題庫拿，不再花錢。老師審核後會標示「老師已審核」。
- 模型：`claude-sonnet-5-5`（在 `ai-worker/src/index.js` 的 `MODEL`）。
- 部署中繼站：在 `ai-worker` 資料夾執行 `npx wrangler deploy`。
- **建議在 Claude Console 設定每月花費上限**，避免意外被大量使用。
