# 理化小老師 · 測試版

## 怎麼打開
直接用滑鼠**雙擊 `index.html`**，用 Chrome 或 Edge 打開即可，不需要安裝任何東西、不用連 AI。

## 測試版做得到的
- **題型**：等加速度直線運動（煞車、加速、求時間、求滑行距離），題目要有數字和單位（m/s、km/h、秒、m/s²、公尺）。
- **一步一步講解**：定義正方向 → 列已知數 → 代公式 → 解釋答案的意思。
- **找學生錯在哪**：填入學生的答案，會指出常見錯誤（正負號相反、忘了除以時間、把變速當等速、漏了 ½……）。
- **動畫**：車子移動＋速度／加速度箭頭＋速度–時間圖（面積＝位移），可開語音朗讀。
- **題庫**：問過的題目會存起來（換個問法也認得出來），統計被問次數、學生常見錯誤答案；老師後台可以審核、刪除、匯出備份。

## 雲端題庫（Firebase）
- `firebase-config.js` 填好 Firebase 設定後，題庫自動改存雲端（右上角會顯示「☁ 雲端題庫」）；沒填時顯示「💻 本機題庫」，存在這台電腦。
- `firestore.rules` 是資料庫安全規則：學生只能新增題目、把被問次數加 1；**只有老師（a1011755@gmail.com）登入後**才能審核、刪除。修改後要貼到 Firebase 主控台 → Firestore Database → 規則 → 發布。
- 老師登入在「題庫（老師後台）」分頁。直接雙擊檔案打開時可能無法登入，放上網站後就可以。

## 目前的限制（之後的正式版再做）
- 其他題型（電路、浮力、化學……）測試版不會，會先放進「待 AI 解答」清單 → 正式版接上 Claude AI 來回答，答案存進題庫，下次同一題就不再花 token。
- 還沒放上網路 → 正式版可以放到 GitHub Pages。
